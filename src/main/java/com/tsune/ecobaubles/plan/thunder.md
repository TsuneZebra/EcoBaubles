# 雷神之怒
## 护身符
常驻被动：攻击敌人时积累1层雷能（最多60层），雷能满时下一次攻击触发"雷神一击"，对目标造成20点伤害并链式传导至周围4格内最多3个敌人（每次传导衰减25%伤害），所有被命中的目标感电10s。当受到致命伤害时，消耗全部雷能召唤落雷护体，获得5s的伤害吸收2和迅捷3，并对周围敌人造成雷能层数×0.5点伤害，冷却时间600s

# 静电护符
## 护身符
常驻被动：攻击敌人时有20%概率使其感电3s，并造成3点额外雷电伤害。雷暴天气时感电概率提升至40%

# 裂雷戒
## 指环
主动技能：在15格内指定位置召唤一道落雷，对目标造成20点伤害并链式传导至周围最多3个敌人，每次传导造成前一次60%的伤害，冷却时间45s

# 闪链指环
## 指环
常驻被动：造成伤害时，闪电链式传导至4格内最多2个其它敌人，造成原始伤害30%的伤害，并使被传导的敌人造成感电1s，冷却3s

# 感电之戒
## 指环
常驻被动：被你感电的敌人（来自任意雷系饰品的感电效果），受到的所有伤害增加15%，且无法回复生命值

# 雷脉腰带
## 腰带
常驻被动：移动时每秒积累1点静电（最多30点），静止时每秒消散2点。每10点静电提供3%移速加成。被近战攻击时释放全部静电，对攻击者造成静电值×0.8点伤害并造成感电静电值×0.2s，静电归零

# 雷眼
## 头部
常驻被动：每隔10s，可透视方块看到20格内生物轮廓，雷暴天气时变为常驻，并且你周围30格内的自然落雷会被引导至最近的敌对生物身上，并额外造成10点伤害

# 雷霆之铠
## 身体
常驻被动：受到近战攻击时有25%概率反击攻击者，造成4点伤害并感电2s。受到的爆炸伤害降低40%

# 霹雳坠
## 吊坠
常驻被动：对敌人造成暴击时，在目标位置召唤一道小型落雷，造成8点额外伤害。若目标处于雨中或水中，伤害提升至12点，冷却8s
