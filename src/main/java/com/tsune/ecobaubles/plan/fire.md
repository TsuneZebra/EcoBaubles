# 炎魔之眼  
## 护身符  
常驻被动（狂战士）：生命值越低时攻击力越高（损失10%生命增加5%攻击和2%移速），当血量降至1点时获得7s的不屈1（无法死亡，冷却时间300s）
可开关被动（“玩火”自焚）：开启时对敌人造成的伤害反弹35%到自己身上，并且对敌人造成的伤害增加50%。

# 炎魔核心
## 护身符
获得抗火效果，攻击可以点燃目标，点燃目标后对敌人造成5s的灼烧效果（每1s扣除1%最大生命值），点燃对同一目标冷却时间为30s，在岩浆中以及灵魂沙上可以获得20%的移速加成。

# 爆炎戒
## 指环
主动技能：将自身点燃并在3s之后引爆自己，对自身造成自身最大生命值的80%的真实伤害（无视护甲），对周围2格内其它生物造成自身最大生命值的150%的真实伤害（无视护甲），冷却时间180s。

# 灰烬指环
## 指环
常驻被动：当血量低于50%时，对周围敌人造成敌人当前生命值的20%的火焰伤害（冷却时间30s）。

# 灼魂戒
## 指环
常驻被动：当被敌人攻击时，自动用火焰锁链连接敌人，每2s吸取敌方3%的当前生命值，溢出的转化为护盾，并且连接其间敌方无法回复生命值，持续14s，敌人离开范围20m后锁链消失，对同一目标冷却时间90s。

# 熔火之心腰带
## 腰带
常驻被动：获得25%的最大生命值加成，处在岩浆中时每秒恢复1点生命值，获得10%的抗性提升。

# 余烬面具
## 头部
常驻被动：获得夜视效果，烟雾、火焰以及岩浆不会阻碍你的视线。注视敌对生物连续超过6s后使其燃烧10s。

# 狂热披风
## 身体
常驻被动：你周围环绕火焰，触碰的敌方会持续收到灼烧效果（每秒造成1的火焰伤害，并且减少10%的治疗量），当你击杀敌人时会造成一次小爆炸对周围敌方造成10点伤害（冷却时间15s）。

# 爆炎吊坠
## 吊坠
常驻被动：当你对生物造成的单次伤害大于该生物最大生命的65%时，你的该次攻击将造成小范围爆炸，点燃范围内除玩家外的生物，并造成7点伤害
