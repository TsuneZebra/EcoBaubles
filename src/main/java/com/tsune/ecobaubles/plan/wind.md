# 风之护符
## 护身符
+10%移速；受到的单次伤害超过6点时触发风之庇护，击退周围所有生物并获得3秒加速
# 凌天坠羽
## 护身符
常驻效果：摔落伤害-60%，移动速度+20%；+1跳跃高度；在受到致命伤害时保持一点血量，并朝斜上空飞去并缓降（如果头上8格内有阻挡，则强力击飞周围生物并造成20点伤害），随后获得风神的庇护（伤害吸收5、生命恢复2、迅捷3、跳跃提升5、抗性提升1）持续8s。冷却时间480s
# 苍风戒
## 指环
按技能键发射一根无限穿透的风箭（无下坠），造成15点无视护甲伤害+最大生命值的25%真实伤害（最高200），冷却时间60s

# 风引指环
## 指环
击杀敌方生物时，在死亡位置吸引小范围内的敌方生物

# 裂风戒
## 指环
+20%拉弓速度；玩家射出的箭飞行速度加20%，且在命中后对命中目标后方小范围内其它生物造成命中伤害的20%伤害

# 风影束带
## 腰带
连续奔跑10秒后获得短暂的“风行”状态：移速+30%、跳跃+1、受到攻击有15%几率无视伤害（闪避）
灵风护环：每过7秒获得1层“风灵印记”（最多5层），每层提升2%移速，受到攻击会消耗全部印记转化为风护盾抵消伤害，每层抵挡15%。

# 风冠
## 头部
被强风包裹全身，获得一个最大生命值50%的风盾，吸收受到伤害的40%，弹射物伤害提升至吸收70%，风盾破裂时击退周围敌人，该护盾在未受到伤害持续40s后恢复或重生

# 风盾回音
## 身体部位 
受到伤害时有15%概率生成风盾，5秒内免疫一次受到的伤害，并将该次免疫本应受到的伤害反伤给攻击者，并以攻击者为中心对2格内敌方造成10点范围伤害

# 疾风镣
## 吊坠
装备后，跳跃后可以在最高点附件按跳跃键踏风，可借助背靠墙壁加强该行为。每次跳跃高度递增（最高+8格）

# 风灵
## 任意部位
蕴含着不可描述的风的力量，你能感受到来自四面八方的每一丝微弱的风
增强其它所有风类饰品效果效果：
风之护符：移速额外+5%，触发阈值降低20%
凌天坠羽：移速额外+5%，飞升高度+20%，击退伤害+20%，庇护时间+4s
苍风戒：最大生命值伤害变为33%
风引指环：吸引持续时间+0.5s
拉弓速度额外+10%，穿透范围伤害变为35%
风影束带：风行闪避+5%，风灵印记抵挡伤害变为18%
风冠：最大生命值护盾变为75%
风盾回音：造成伤害变为16点
