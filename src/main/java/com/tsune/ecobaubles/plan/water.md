# 海神恩赐
## 护身符
常驻被动：受到的伤害降低20%，获得生命恢复1，在水中的移动速度提升20%，获得生命恢复2。当自身或周围玩家生命值低于50%时，立即恢复满自身和周围玩家血量（范围8格），并且在获得15秒的伤害吸收3效果（冷却时间300秒）

# 潮涌护符
## 护身符
常驻被动：脱离战斗15s以后获得一个最大生命值20%的护盾。在水下的移动速度增加20%、受到的伤害减少20%

# 疗愈指环
## 戒指
常驻被动：每次受到伤害时，对自身及3格内友方玩家回复自身最大生命值的5%的治疗量。

# 泉御之戒
## 戒指
主动技能：开启后10s内免疫所有伤害并将其储存，技能结束后15s内每秒逐渐结算储存的伤害（冷却时间60s）

# 波光指环
## 戒指
常驻被动：攻击命中敌人使其移动速度降低20%，并造成小范围的水之波动，回复周围友方1点生命，冷却4秒

# 深渊头盔
## 头部
常驻被动：增加20%最大生命值；获得水下呼吸，水下夜视，基于你在水中的深度获取伤害提升（每4格提升8%），在雨天获得生命恢复2。

# 潮汐腰带
## 腰带
常驻被动：当自身受到的负面效果时，治疗4点生命值，并将此次负面效果持续时间减少40%，受到增益效果时，使周围玩家也获得该增益效果的30%持续时间。

# 水纹长袍
## 身体
常驻被动：受到的投掷物伤害降低35%，自身生命值高于90%时为5格内玩家提供生命恢复1；受到近战伤害时，使攻击者溺水并无法移动，持续1s（冷却2s）

# 水心圣坠
## 吊坠
常驻被动：当生命值满时，受到的一切治疗（饰品治疗、生命恢复buff、瞬间恢复药水等魔法治疗）转化为伤害吸收，上限为最大生命值的30%；自身对周围玩家的治疗效果同样适用此转化

# 水灵
## 饰品（任意槽位）
蕴含着不可描述的水的力量，你能感受到来自四面八方的每一丝微弱的水流。

水灵增强效果：
- 海神恩赐：触发阈值提高（50%→65%），吸收持续时间+5s（15s→20s）
- 潮涌护符：护盾从20%→30%最大生命值，脱离战斗时间缩短（15s→10s）
- 疗愈指环：治疗量5%→8%最大生命值，治疗范围+1格（3→4格）
- 泉御之戒：冷却时间-15s（60s→45s）
- 波光指环：治疗量1→2点，冷却时间4s→3s
- 深渊头盔：深度伤害加成每4格+8%→+12%
- 潮汐腰带：受到负面效果治疗量4→6点，增益效果分享时间比例30%→50%
- 水纹长袍：投掷物伤害减少35%→50%，触发生命恢复的血量阈值90%→80%
- 水心圣坠：伤害吸收上限30%→40%最大生命值
