# 海神恩赐
## 护身符
常驻被动：受到的伤害降低80%，获得生命恢复1，在水中的移动速度提升20%，获得生命恢复2。当自身或周围玩家生命值低于50%时，立即恢复满自身和周围玩家血量（范围8格），并且在获得15秒的伤害吸收3效果（冷却时间300秒）

# 潮涌护符
## 护身符
常驻被动：脱离战斗15s以后获得一个最大生命值20%的护盾。在水下的移动速度增加20%、受到的伤害减少20%

# 疗愈指环
## 戒指
常驻被动：持续为周围3格以内的友方单位回复生命值，每5秒回复最大生命值的5%。

# 激流勇进
## 戒指
主动技能：发射一个大水球禁锢命中的敌人及周围的敌人，使其溺水并无法移动，持续5秒，水球破损后对其减少20%的攻击速度和移动速度（冷却时间40s）

# 波光指环
## 戒指
常驻被动：攻击命中敌人使其移动速度降低20%，并造成小范围的水之波动，回复周围友方1点生命，冷却7秒

# 深渊头盔
## 头部
常驻被动：获得水下呼吸，水下夜视，基于你在水中的深度获取伤害提升（每4格提升8%），在雨天获得生命恢复2。

# 潮汐腰带
## 腰带
常驻被动：当自身受到的负面效果时，治疗4点生命值，并将此次负面效果持续时间减少40%，受到增益效果时，使周围玩家也获得该增益效果的30%持续时间。

# 水纹长袍
## 身体
常驻被动：受到的投掷物伤害降低35%，自身生命值高于90%时为5格内玩家提供生命恢复1

# 水心圣坠
## 吊坠
常驻被动：当你对生命值低于25%的生物造成伤害时，立即召唤一股水浪冲击目标及周围敌人，对击中的目标造成目标已损失生命值25%伤害（最多50点）并溺水3s，同时对自身治疗造成的总伤害的40%，冷却20s

# 水灵
## 饰品（任意槽位）
蕴含着不可描述的水的力量，你能感受到来自四面八方的每一丝微弱的水流。

水灵增强效果：
- 海神恩赐：触发阈值提高（50%→65%），吸收持续时间+5s（15s→20s）
- 潮涌护符：护盾从20%→30%最大生命值，脱离战斗时间缩短（15s→10s）
- 疗愈指环：治疗量5%→8%最大生命值，治疗范围+1格（3→4格）
- 激流勇进：锁定时间+2s（5s→7s），冷却时间-10s（40s→30s）
- 波光指环：治疗量1→2点，冷却时间7s→5s
- 深渊头盔：深度伤害加成每4格+8%→+12%
- 潮汐腰带：受到负面效果治疗量4→6点，增益效果分享时间比例30%→50%
- 水纹长袍：投掷物伤害减少35%→50%，触发生命恢复的血量阈值90%→80%
- 水心圣坠：伤害比例25%→35%，自身治疗比例40%→60%，冷却时间-5s（20s→15s）
