# 寒极神魄
## 护身符
**蕴含着极其强大的极寒之灵的力量，散发出的寒气仿佛要将整个世界冻结**
- 你10格范围内的所有敌方生物的移动速度降低20%
- 当你受到致命伤害时，你不会死亡，护符爆发出强大的力量将整个世界冻结，持续12s，冷却时间720s

# 霜蚀护符
## 护身符
攻击你的生物有30%概率被你的寒气所伤，在3秒内移动速度降低40%并每秒受到1.5点伤害

# 霜刃指环
## 戒指
你的每次攻击都将附带2点额外的冰冻伤害，并使目标移动速度和攻击速度降低20%

# 寒狱之戒
## 戒指
按技能键冻结5格范围内的所有敌对生物，其受到伤害或3s后破冰，破冰时根据技能冻结的敌人数量造成3+(2*敌人数量)点伤害

# 霜怨指环
## 戒指
每当你受到伤害时，该戒指都会存储该伤害量的60%，当你的生命值降低至40%以下时，戒指将会爆发冰霜之力，对周围5格内的所有敌人造成伤害，伤害量为之前存储的伤害平均分担到每个敌人身上

# 寒域腰带
## 腰带
根据你的移动速度积累/消散你身边的寒气（静止时每秒5点，根据移动速度降低每秒积累，直到每秒-4点，寒气值的最大值60点，最小值0点）。根据你身边的寒气值，减少生物发现你的距离（每点寒气值降低1.2%），降低4格内敌对生物的移动速度（每点寒气值降低1%），3格内敌对生物每秒受到寒气伤害（每8点寒气值造成1点伤害）

# 冰魄之冠
## 头部
- 在冰雪相关群系时，移动速度+15%，获得10%伤害减免效果
- 穿戴该饰品时，自动从头部发射寒冰攻击周围的敌人（一条寒冰粒子直线效果），造成4点伤害并使其移动速度降低20%，每次攻击间隔3s

# 冰殇披甲
## 身体
**你的皮肤将被寒冰所侵蚀，获得冰甲**
获得15点护甲值，5点盔甲韧性，对你造成伤害的生物将在2s内降低20%攻击速度。当你存在冰甲时，生命值低于35%时，冰甲碎裂，对自己及周围所有生物造成自身已损生命值的40%伤害，冰甲将在生命值大于60%恢复

# 极寒之心
## 吊坠
- 你受到伤害时有 10% 概率冰封自身 3 秒（无法移动，但免疫所有伤害），期间回复4点生命
- 冰封解除时，击退周围敌人并使其获得缓慢2效果持续5s

# 冰灵
## 任意部位
蕴含着不可描述的冰的力量，你能感受到来自四面八方的每一粒冰晶。

冰灵增强效果：
- 寒极神魄：光环范围10→12格，冻结世界12s→15s，冷却时间720s→600s
- 霜蚀护符：触发率30%→45%，持续时间3s→4s，每秒伤害1.5→2
- 霜刃指环：额外伤害2→3，减速时长3s→4s
- 寒狱之戒：冻结时长3s→5s，破冰伤害3+(2*n)→5+(3*n)，冷却时间40s→30s
- 霜怨指环：伤害存储比例60%→80%，触发阈值40%→50%
- 寒域腰带：最大寒气值60→80，减速幅度增强
- 冰魄之冠：移动速度加成15%→20%，攻击间隔3s→2s，攻击伤害4→6
- 冰殇披甲：护甲值+15→+20，盔甲韧性+5→+8
- 极寒之心：触发概率10%→15%，冰封时长3s→4s，期间回复4→6点生命
